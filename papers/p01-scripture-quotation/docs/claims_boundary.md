# Claims Boundary

This boundary applies to `FID-056-P01`. It does not authorize claims for other
papers proposed under the FID-056 research program.

Valid claims:

- A named system produced specified authoritative-quotation metrics under a named
  protocol version, scenario set, condition, run date, and scoring specification.
- A condition showed specified failure modes such as wrong reference, wrong
  version, truncation, refusal, blended quotation, or deterministic render
  failure.
- Structured reference detection and deterministic rendering can be evaluated
  separately from native text generation.

Invalid claims:

- A system is theologically correct.
- A system is pastorally safe.
- A system is legally compliant.
- A system is approved for deployment.
- A partner product is endorsed by Fide AI.
- A result generalizes beyond the named systems, dates, source editions,
  scenarios, and scoring rules.

The Apologist Project may publish a separate companion post describing its own
solution. That companion publication should not be treated as part of Fide AI's
independent protocol unless explicitly incorporated through a reviewed release.
