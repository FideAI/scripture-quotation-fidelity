# Data Availability

The public release candidate includes deidentified derived scores sufficient to
reproduce every aggregate rate, contrast, interval, and figure in Paper 02
without network access. The release also includes analysis scripts, a
release-safe target registry, exact treatment templates, the public derivative
of the prospective lock, an execution seal, and a manifest of released files.

The release excludes raw model messages, provider response identifiers,
credentials, authoritative passage text, local paths, private execution code,
and calibration traces. Raw evidence is retained privately for audit. The
shared experimental implementation is maintained separately from the public
paper package. Confirmatory execution used revision
`dbb1514cde5c7a8e17944d09cf16d0ed1ee619cc`. A prospective correction to one
secondary scorer was committed separately as
`45f6114580f2e2a5e1823cd65c6156987f48f90b`; it did not generate the released
rows. The executed tree must not be confused with the corrected revision. It is
publicly reachable at the
[exact executed commit](https://github.com/apologist-project/llm-scripture-fidelity/commit/dbb1514cde5c7a8e17944d09cf16d0ed1ee619cc).
