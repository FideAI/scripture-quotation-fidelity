# Responsible Use

This evaluation methodology is a measurement method. It is not:

- theological certification;
- pastoral safety approval;
- legal advice;
- copyright clearance;
- product endorsement;
- deployment approval.

Authoritative quotation matters because a system can be fluent while still
misquoting, blending editions, omitting required text, or presenting paraphrase
as quotation. Users should treat study results as evidence about specific
systems under specific conditions, not as a general statement about all AI use in
a domain.

For restricted or licensed source works, researchers must obtain appropriate
authorization before retrieving, storing, displaying, or redistributing text.
